Product

Shared EV charging for apartment garages.

Local load management for apartment and condo buildings. It shares the building's power between cars and aims to keep charging in garages with no mobile or Wi-Fi signal. Status: prototype in development.

Three parts, one system

  • Chargers on a wireless mesh

    Each charger carries its own board and joins a wireless mesh that links parking floors.

  • Meters

    Each charger measures its own energy use. The system measures the building's total use too.

  • Load management

    The building's available power is shared between chargers. The decision is made locally.

From one circuit board to a whole garage

Mesh network

A mesh that aims to reach every floor.

Chargers talk to each other over a wireless mesh. The mesh needs no mobile plan and no building Wi-Fi. Its radio link has longer range than common short-range radios, which should let it reach between floors.

Status: prototype in development. Range is not yet proven in a building.

View the technology or follow one charging session.

Metering

Measure what each charger uses.

Each charger measures its own energy, voltage, current and power. The building's total power use is measured too and passed to the load-management unit. With both readings, sharing aims to stay under the building limit.

Meter values are reported to the charging back office.

Measurement accuracy is not yet specified.

See the metering section

Load management

Many cars, one building limit.

Every building has a limit on how much power it can draw. When many residents plug in at once, uncontrolled charging can pass that limit. A load-management unit in the building shares the available power between cars and aims to keep total use under the limit. It decides locally, so it should keep working without the internet.
