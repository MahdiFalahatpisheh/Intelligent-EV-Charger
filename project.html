Project

What it is

An engineering project that aims to add EV charging to apartment buildings by managing the capacity they already have, not by upgrading the service.

Project

Status

Status: prototype in development. The hardware is a first-revision prototype of our charger, Requirements and design are working drafts. Not validated on a real installation, and not a finished product.

Project

Scope

The proposed first version covers AC charging control, per-charger metering, local capacity sharing, a wireless mesh, an OCPP link, and local logging and diagnostics.

Project

Future work

Solar, battery storage and vehicle-to-grid are possible later work, not in the first version.

Build log

What has been done

  • Early October: Requirements, design drafts and a gap analysis written. First-revision schematic reviewed.
  • Early October: First board-validation scripts written and reviewed, for the bench.
  • Mid October: First version of this website built.
  • Mid October: Product settled: control board and wireless-mesh radio built into our own charger.

Roadmap

Next steps

  • Test capacity sharing in simulation, then on the bench.
  • Prove our charger on the bench before any real charging session.
  • Test the wireless mesh in realistic garage conditions.
  • Validate the full system on a real installation, after a safety review.

Audience

Who it is for

  • Building owners and managers: the aim is to add charging for residents without first upgrading the electrical service.
  • Residents: a share of the building's capacity, set by a sharing policy still to be defined, and charging that aims to keep going when the internet is down.
  • Utilities: the aim is for charging demand to stay within a set limit, not add unmanaged peaks to the grid.
